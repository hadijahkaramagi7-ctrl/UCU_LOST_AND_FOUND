# UCU Campus Lost and Found

A responsive web application for reporting lost/found items at Uganda Christian University, claiming found items privately, and confirming returns.

## Exam Information

- **Course:** CSC1202 Web and Mobile Applications Development
- **Project Type:** 100% Project-Based Exam
- **Group Members:** 6

## Tech Stack

- **Frontend:** React (Vite), React Router, Axios, Tailwind CSS
- **Backend:** Node.js, Express, mysql2, bcrypt, jsonwebtoken
- **Database:** MySQL 8

## Project Structure

- `backend/` - Express API and server logic
- `frontend/` - React user interface
- `db/` - Database setup scripts and sample data
- `docs/` - Milestone evidence and documentation
